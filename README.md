# 《听见古典》 HEAR CLASSICS

> **面向中文世界的高维古典音乐实证导听系统与档案库**  
> *The Art of Attentive Listening · Canonical Musicology Archive*

---

## 🏛 项目概述

《听见古典》（Hear Classics）是一座具有现代美术馆与学术档案馆气质的高品质古典音乐数字化学习平台。平台拒绝空洞玄虚的感性形容词与五线谱识谱门槛，完全以**真实声音动作、耳朵可验证的声学事实、结构性时间骨架**为核心，带听众从“听见第一声变化”开始，系统建立终身受益的音乐审美体系。

全站基于 **Next.js 14 App Router** 全静态预渲染（SSG）架构构建，包含 **470+ 静态路由**、**70 余万字原创实证导听文献**，零第三方后端依赖，支持纯离线与全球极速边缘分发。

## 🎵 核心系统与功能板块

### 1. 12 单元 · 144 讲阶梯式系统大纲
- **单元 I**：第一次认真听（感官唤醒 · 破除乐理神话）
- **单元 II**：认识声音与乐队（音色解构 · 管弦乐团全景）
- **单元 III**：音乐怎样说话（语法基础 · 旋律、节奏与织体）
- **单元 IV**：听见结构与图景（时间建筑 · 奏鸣曲式与变奏）
- **单元 V**：早期音乐与巴洛克（复调对位 · 巴赫的精密宇宙）
- **单元 VI**：古典主义与贝多芬（理性光芒 · 维也纳三大巨匠）
- **单元 VII**：浪漫主义的多条道路（精神探险 · 个人意志狂飙）
- **单元 VIII**：二十世纪与当代入口（光影解构 · 印象主义与先锋）
- **单元 IX**：室内乐与独奏深入（私密对话 · 智者的微观博弈）
- **单元 X**：声乐、歌剧与舞台（综合艺术 · 咏叹调与戏剧风暴）
- **单元 XI**：版本比较与独立判断（实证鉴赏 · 大师指尖的哲学对决）
- **单元 XII**：建立自己的聆听世界（终身伴侣 · 自主构建个人乐单）

> 每讲课严格遵循 **12 步结构化导听模板**：课前定向、核心声音动作、声学事实解构、客观检验问答、拓展反思与用时指标。

### 2. 传世名作典藏知识库（300+ 部大作）
- 涵盖巴洛克、古典、浪漫、晚期浪漫、20世纪先锋与当代中国交响全谱系；
- 包含 60 部深度解构专著（带完整乐章时轴剖析、听觉锚点与版本推荐）；
- 补全收录珀塞尔《狄多的哀歌》、马勒《第一交响曲“巨人”》、肖邦《降D大调夜曲》等学术关键坐标。

### 3. 时代历史声音长卷（7 大断代演进）
- 中世纪与文艺复兴（Ars Antiqua & Renata）
- 巴洛克时代（Barocco & Concerto）
- 古典主义（Classicism & Symphonia）
- 浪漫主义狂潮（Romanticismo）
- 晚期浪漫与民族乐派（Late Romantic & National）
- 印象派与二十世纪（Modernismo & Color）
- 当代与中国交响（Chinese Symphonic）

### 4. 互动黑胶唱盘机与 Web Audio 原生调色盘
- **黑胶唱盘交互台**：支持唱臂吸附、黑胶转速视觉动效与多乐章试听；
- **听觉调色盘**：使用 Web Audio API 原生振荡器与滤波网络，零外部音频资源实时合成德彪西全音阶微光、肖邦降E大调和弦、巴赫纯净大三度与贝多芬降E雷霆。

### 5. 辅助展馆与档案
- **声音实验室（Sound Lab）**：音色辨析、声部对位、变奏捕捉等互动听力练习；
- **版本比较展厅**：主观意志派 vs 客观精准派双盲试听；
- **作曲家星系**：83 位跨越八百年的大师图谱；
- **32 种乐器与 36 种体裁展馆**；
- **个人听觉手记档案**。

## 💻 本地运行与开发

### 环境要求
- Node.js 18.17+ 或 20+
- npm / pnpm / yarn

### 安装依赖
```bash
npm install
```

### 启动本地开发服务
```bash
npm run dev
```
打开浏览器访问 `http://localhost:3000`。

### 全静态构建导出
```bash
npm run build
```
静态构建产物将输出至 `out/` 目录，可直接托管至任何静态 CDN、GitHub Pages、Vercel 或局域网 HTTP 服务器。
